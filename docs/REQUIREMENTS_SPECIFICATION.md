# 需求规格说明书

## 1. 文档目的

本文档用于说明《基于 Text2SQL 与 RAG 的大模型智能问答系统》的需求范围、功能目标、用户角色和验收口径。当前版本先建立课程审核所需的文档框架，后续随着实现推进补充细节和截图。

## 2. 项目背景

本项目面向结构化数据库问答场景，用户可以通过自然语言提问，系统将问题转换为 SQL 并查询数据库。第二阶段扩展 RAG 文档问答能力，用于解释概念、字段口径和系统说明。

初始演示领域选择股票数据。股票数据仅用于课程演示和 Text2SQL 测试，不用于真实投资建议。

## 3. 用户角色

| 角色 | 说明 |
| --- | --- |
| 普通用户 | 输入自然语言问题，查看 SQL、表格结果和文字总结 |
| 系统管理员 | 管理数据库连接、知识库文档和测试用例 |
| 开发/测试人员 | 维护接口、测试问题集、执行结果和报告材料 |

## 4. 功能性需求

| 编号 | 功能 | 当前阶段范围 | 优先级 |
| --- | --- | --- | --- |
| FR-01 | 自然语言问题输入 | 前端提供问题输入和提交按钮 | P0 |
| FR-02 | Text2SQL 转换 | 后端先返回 mock SQL，后续接入大模型 | P0 |
| FR-03 | 数据库 schema 获取 | 先返回 mock schema，后续读取真实数据库 | P0 |
| FR-04 | SQL 安全校验 | 初版只允许单条 `SELECT` 查询 | P0 |
| FR-05 | 查询结果展示 | 前端展示表格、SQL 和摘要 | P0 |
| FR-06 | 错误处理与反馈 | 展示接口错误和本地 mock 状态 | P1 |
| FR-07 | 测试用例管理 | 使用 JSON 维护第一批测试问题 | P1 |
| FR-08 | RAG 文档问答 | 第二阶段实现，当前只保留设计方向 | P2 |
| FR-09 | 多轮上下文 | 后续扩展，当前不实现 | P2 |

## 5. 非功能性需求

| 类别 | 要求 |
| --- | --- |
| 可维护性 | 仓库结构清晰，后端、前端、文档、测试分离 |
| 安全性 | 不提交 API Key、`.env`、虚拟环境、缓存和临时数据库文件 |
| 可解释性 | 展示生成 SQL，便于调试和课程答辩说明 |
| 可扩展性 | 后续可替换 mock 服务为真实 LLM、SQLite/MySQL 和 RAG 模块 |
| 易用性 | 前端页面至少包含输入、SQL、结果和状态区域 |

## 6. 外部接口需求

| 接口 | 说明 |
| --- | --- |
| `GET /api/health` | 后端健康检查 |
| `GET /api/schema` | 获取数据库表结构 |
| `POST /api/text2sql/query` | 提交自然语言问题并返回 SQL 与结果 |

## 7. 数据需求

初始数据库方向为股票演示数据，至少包含股票基础信息、日行情和财务指标三类表。详细字段见 `docs/DATASET_DESIGN.md`。

## 8. 验收标准

1. 仓库具备 `backend/`、`frontend/`、`docs/`、`tests/` 基础结构。
2. 后端能够启动并提供三个基础 API。
3. 前端能够展示问答输入、SQL、表格结果和系统状态。
4. 文档能够覆盖需求规格、系统设计、测试报告和小组分工。
5. 测试目录包含第一批股票相关自然语言问题。
