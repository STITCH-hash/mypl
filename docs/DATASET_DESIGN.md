# 股票演示数据集设计

## 1. 数据集定位

股票数据集用于演示 Text2SQL 能力，并为后续 RAG 概念解释预留知识背景。第一阶段不追求全量金融数据，也不做实时投资分析，而是选择少量、结构稳定、适合 SQL 查询的数据，让系统能够稳定完成自然语言到 SQL 的课程演示。

本项目采用 AkShare 作为股票数据来源，但系统运行时不直接让 Text2SQL 查询 AkShare。推荐流程是：

```text
AkShare
→ Python 采集脚本
→ 字段清洗和英文列名统一
→ 写入本地 SQLite 数据库
→ Text2SQL 查询 SQLite
→ 前端展示 SQL、表格和摘要
```

股票数据仅用于课程项目演示、数据库问答测试和字段概念解释，不用于真实投资建议。系统回答涉及股票数据时，应提示数据来自课程演示库，可能不是实时数据，也不能作为买卖依据。

## 2. 第一阶段采集范围

第一阶段建议选择约 30 支 A 股股票，覆盖 6 个左右行业，每个行业约 5 支股票。可优先覆盖银行、消费、新能源、半导体、医药、软件服务等常见行业，方便构造行业筛选、排序、聚合和时间范围查询。

历史行情建议采集最近 1 年日线数据。按 30 支股票、每年约 240 个交易日估算，`daily_prices` 表约 7200 行，数据量适合 SQLite，查询速度快，也便于课堂演示和测试报告复现。

第一阶段只建立三张核心表：

| 表 | AkShare 来源 | 作用 |
| --- | --- | --- |
| `stocks` | `stock_info_a_code_name()` + 少量 `stock_individual_info_em(symbol)` | 保存股票代码、名称、行业、上市日期、交易所、市场等基础信息 |
| `daily_prices` | `stock_zh_a_hist(symbol, period="daily", start_date, end_date, adjust="")` | 保存最近一年日行情，支持价格、成交量、成交额、涨跌幅、换手率等查询 |
| `stock_quotes` | `stock_zh_a_spot_em()` | 保存一次最新行情快照，支持最新价、市盈率、市净率、市值、最新成交额等查询 |

暂不在第一阶段实现全量 A 股、分钟级行情、实时轮询、新闻情绪、完整财务报表、RAG 知识库和 Agent 框架。

## 3. 初始数据库表设计

### `stocks`：股票基础信息表

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| `stock_id` | INTEGER | 主键，股票内部 ID，由本系统生成 |
| `symbol` | VARCHAR | 股票代码，例如 `600000` |
| `stock_name` | VARCHAR | 股票名称 |
| `exchange` | VARCHAR | 交易所，例如 SSE、SZSE、BSE，可由代码规则或接口字段整理 |
| `industry` | VARCHAR | 所属行业，优先来自 `stock_individual_info_em(symbol)` |
| `list_date` | DATE | 上市日期 |
| `market` | VARCHAR | 市场类别，第一阶段统一为 A 股或按沪深京分类 |

主键为 `stock_id`，`symbol` 建议设置唯一约束。该表被 `daily_prices` 和 `stock_quotes` 通过 `stock_id` 或 `symbol` 引用。适合支持“查询所有在上交所上市的股票”“某行业有哪些股票”“某股票的基础信息是什么”等问题。

### `daily_prices`：历史日行情表

| 字段 | 类型建议 | AkShare 中文字段 | 说明 |
| --- | --- | --- | --- |
| `price_id` | INTEGER | 本系统生成 | 主键，行情记录 ID |
| `stock_id` | INTEGER | 本系统关联 | 外键，关联 `stocks.stock_id` |
| `symbol` | VARCHAR | 股票代码 | 股票代码，便于导入和查询 |
| `trade_date` | DATE | 日期 | 交易日期 |
| `open_price` | DECIMAL | 开盘 | 开盘价 |
| `close_price` | DECIMAL | 收盘 | 收盘价 |
| `high_price` | DECIMAL | 最高 | 当日最高价 |
| `low_price` | DECIMAL | 最低 | 当日最低价 |
| `volume` | BIGINT | 成交量 | 当日成交量 |
| `turnover` | DECIMAL | 成交额 | 当日成交额 |
| `amplitude` | DECIMAL | 振幅 | 当日价格振幅 |
| `change_pct` | DECIMAL | 涨跌幅 | 当日涨跌百分比 |
| `change_amount` | DECIMAL | 涨跌额 | 当日价格涨跌额 |
| `turnover_rate` | DECIMAL | 换手率 | 当日换手率 |

主键为 `price_id`，建议对 `(symbol, trade_date)` 建唯一索引。该表是 Text2SQL 演示主表，适合支持“最近一个交易日成交量最高的 10 支股票”“某股票最近一年的最高收盘价”“过去 30 个交易日涨幅最高的股票”等问题。

### `stock_quotes`：最新行情快照表

| 字段 | 类型建议 | AkShare 中文字段 | 说明 |
| --- | --- | --- | --- |
| `quote_id` | INTEGER | 本系统生成 | 主键，行情快照 ID |
| `stock_id` | INTEGER | 本系统关联 | 外键，关联 `stocks.stock_id` |
| `symbol` | VARCHAR | 代码 | 股票代码 |
| `snapshot_date` | DATE | 采集日期 | 快照采集日期 |
| `latest_price` | DECIMAL | 最新价 | 快照时的最新价 |
| `change_pct` | DECIMAL | 涨跌幅 | 快照时的涨跌幅 |
| `volume` | BIGINT | 成交量 | 快照时的成交量 |
| `turnover` | DECIMAL | 成交额 | 快照时的成交额 |
| `turnover_rate` | DECIMAL | 换手率 | 快照时的换手率 |
| `pe_dynamic` | DECIMAL | 市盈率-动态 | 动态市盈率 |
| `pb_ratio` | DECIMAL | 市净率 | 市净率 |
| `total_market_value` | DECIMAL | 总市值 | 总市值 |
| `circulating_market_value` | DECIMAL | 流通市值 | 流通市值 |

主键为 `quote_id`，建议对 `(symbol, snapshot_date)` 建唯一索引。该表用于补足历史行情中没有的估值和市值信息，适合支持“哪些股票当前市盈率低于 20”“哪些股票总市值最高”“各行业平均市盈率是多少”等问题。

## 4. 后续可扩展表

第一阶段不强制实现以下表，待 Text2SQL 最小闭环稳定后再加入。

| 表 | 来源建议 | 用途 |
| --- | --- | --- |
| `sectors` | `stock_board_industry_name_em()` | 行业或板块列表 |
| `stock_sector_map` | `stock_board_industry_cons_em(symbol)` | 股票与行业/板块关联，支持更复杂多表 JOIN |
| `market_news` | `stock_news_em(symbol)` | 个股新闻，适合后续 RAG 或混合问答 |
| `financial_indicators` | 后续财务指标接口 | 完整财务指标分析，第一阶段先用 `stock_quotes.pe_dynamic` 和 `stock_quotes.pb_ratio` 替代部分估值查询 |

## 5. 示例自然语言问题

### 单表查询

1. 查询所有在上交所上市的股票。
2. 查询股票代码为 600000 的股票名称和所属行业。
3. 查询所有 A 股市场中的股票基础信息。
4. 查询 2020 年以后上市的股票有哪些。

### 日行情查询

5. 查询某支股票最近 30 个交易日的收盘价走势。
6. 某支股票最近一年的最高收盘价是多少。
7. 查询某股票在 2024 年第一季度的平均成交量。
8. 最近 30 个交易日收盘价涨幅最高的 5 支股票是什么。

### 最新行情快照查询

9. 哪些股票当前市盈率低于 20。
10. 当前市净率最低的 10 支股票有哪些。
11. 当前总市值最高的 10 支股票有哪些。
12. 当前成交额最高的 10 支股票有哪些。

### 多表连接

13. 查询软件服务行业股票的最新价和涨跌幅。
14. 查询银行行业中当前市盈率最低的 5 支股票。
15. 查询每支股票最近一个交易日的收盘价和当前最新价。
16. 查询各行业最新行情的平均涨跌幅。

### 聚合统计

17. 各行业分别有多少支股票。
18. 各行业平均市盈率是多少。
19. 最近一个交易日全市场平均涨跌幅是多少。
20. 每个行业最近一个交易日的平均成交额是多少。

### 排序 Top-N 查询

21. 最近一个交易日成交量最高的 10 支股票是什么。
22. 最近一个交易日涨幅最高的 5 支股票有哪些。
23. 最近一年最高收盘价最高的 10 支股票有哪些。
24. 当前换手率最高的 10 支股票有哪些。

### RAG 概念解释

25. 市盈率是什么意思。
26. 市净率是什么意思。
27. 成交量和成交额有什么区别。
28. 为什么不能只根据市盈率判断股票是否便宜。

### Text2SQL + RAG 混合问答

29. 查询市盈率低于 20 的股票，并解释市盈率低可能代表什么。
30. 找出最近一个交易日涨幅最高的 5 支股票，并说明涨跌幅字段的含义。
31. 查询当前总市值最高的 5 支股票，并解释总市值是什么意思。
32. 查询某股票最近 30 个交易日的走势，并说明为什么短期走势不能直接作为投资建议。

## 6. RAG 知识库文档建议

| 文档类型 | 建议内容 | 用途 |
| --- | --- | --- |
| 股票基础概念说明 | 股票、交易所、行业、上市日期、市场类型等概念 | 回答基础概念类问题 |
| 估值指标解释 | 市盈率、市净率、市值、流通市值等指标定义和局限性 | 解释 `stock_quotes` 中的估值和市值字段 |
| 行情字段说明 | 开盘价、收盘价、最高价、最低价、成交量、成交额、涨跌幅、换手率等字段口径 | 帮助用户理解 `daily_prices` 和 `stock_quotes` 查询结果 |
| AkShare 数据来源说明 | 使用的接口、采集时间、字段映射、数据非实时限制 | 说明课程数据来源和可复现方式 |
| 常见投资风险提示 | 数据滞后、模型误差、指标局限、市场波动、非投资建议声明 | 控制演示边界和风险表达 |
| 系统使用说明 | 如何提问、如何查看 SQL、如何理解表格和图表 | 支持用户上手系统 |
| SQL 查询示例说明 | 常见自然语言问题与 SQL 示例 | 后续用于 SQL 示例检索或 few-shot prompt |

RAG 文档用于解释概念、字段和系统规则，不用于给出具体投资建议。回答中如果涉及股票选择、估值判断或风险判断，应明确提示“仅为课程演示和指标解释，不构成投资建议”。
