# 股票演示数据集设计

## 1. 数据集定位

股票数据集用于演示 Text2SQL 和 RAG 能力，不用于真实投资建议。它的价值在于数据结构清晰、查询类型丰富，既能支持基础筛选、排序、聚合、时间范围查询，也能支持行业、财务指标和新闻摘要等多表关联问题。

系统回答涉及股票数据时，应明确说明数据来自课程演示库，可能不是实时数据，也不代表真实市场情况。任何关于估值、风险或指标含义的解释都只能作为概念说明，不能构成买卖建议。

## 2. 初始数据库表设计

### `stocks`：股票基础信息表

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| `stock_id` | INTEGER | 主键，股票内部 ID |
| `symbol` | VARCHAR | 股票代码，例如 `600000` |
| `stock_name` | VARCHAR | 股票名称 |
| `exchange` | VARCHAR | 交易所，例如 SSE、SZSE |
| `industry` | VARCHAR | 所属行业 |
| `list_date` | DATE | 上市日期 |
| `market` | VARCHAR | 市场类别，例如 A 股、港股、美股 |

主键为 `stock_id`。该表被 `daily_prices`、`financial_indicators`、`market_news`、`watchlists` 和 `stock_sector_map` 通过 `stock_id` 引用。适合支持“查询所有在上交所上市的股票”“某行业有哪些股票”“某股票的基础信息是什么”等问题。

### `daily_prices`：日行情表

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| `price_id` | INTEGER | 主键，行情记录 ID |
| `stock_id` | INTEGER | 外键，关联 `stocks.stock_id` |
| `trade_date` | DATE | 交易日期 |
| `open_price` | DECIMAL | 开盘价 |
| `close_price` | DECIMAL | 收盘价 |
| `high_price` | DECIMAL | 最高价 |
| `low_price` | DECIMAL | 最低价 |
| `volume` | BIGINT | 成交量 |
| `turnover` | DECIMAL | 成交额 |
| `change_pct` | DECIMAL | 涨跌幅，单位可约定为百分比 |

主键为 `price_id`，外键为 `stock_id`。建议对 `(stock_id, trade_date)` 建唯一索引，便于按股票和日期查询。适合支持“最近一个交易日成交量最高的 10 支股票”“某股票最近一年的最高收盘价”“过去 30 个交易日涨幅最高的股票”等问题。

### `financial_indicators`：财务指标表

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| `indicator_id` | INTEGER | 主键，指标记录 ID |
| `stock_id` | INTEGER | 外键，关联 `stocks.stock_id` |
| `report_period` | DATE | 报告期 |
| `pe_ratio` | DECIMAL | 市盈率 |
| `pb_ratio` | DECIMAL | 市净率 |
| `roe` | DECIMAL | 净资产收益率 |
| `revenue` | DECIMAL | 营业收入 |
| `net_profit` | DECIMAL | 净利润 |
| `gross_margin` | DECIMAL | 毛利率 |
| `debt_ratio` | DECIMAL | 资产负债率 |

主键为 `indicator_id`，外键为 `stock_id`。建议对 `(stock_id, report_period)` 建唯一索引。适合支持“哪些股票的市盈率低于 20”“ROE 大于 15% 且负债率低于 50% 的股票有哪些”“各行业平均市盈率是多少”等问题。

### `sectors`：行业或板块表

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| `sector_id` | INTEGER | 主键，板块 ID |
| `sector_name` | VARCHAR | 板块名称 |
| `description` | TEXT | 板块说明 |

主键为 `sector_id`。该表通过 `stock_sector_map` 与 `stocks` 建立多对多关系。适合支持“新能源板块包含哪些股票”“各板块股票数量是多少”“某板块说明是什么”等问题。

### `stock_sector_map`：股票与行业/板块关联表

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| `stock_id` | INTEGER | 外键，关联 `stocks.stock_id` |
| `sector_id` | INTEGER | 外键，关联 `sectors.sector_id` |

联合主键建议为 `(stock_id, sector_id)`。该表用于表达一支股票可以属于多个概念板块，一个板块也可以包含多支股票。适合支持“某股票属于哪些板块”“某板块中成交量最高的股票有哪些”等多表连接问题。

### `market_news`：市场新闻或公告摘要表

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| `news_id` | INTEGER | 主键，新闻 ID |
| `stock_id` | INTEGER | 外键，关联 `stocks.stock_id`，可为空表示市场级新闻 |
| `publish_date` | DATE | 发布日期 |
| `title` | VARCHAR | 标题 |
| `summary` | TEXT | 摘要 |
| `source` | VARCHAR | 来源 |
| `sentiment` | VARCHAR | 情绪标签，例如 positive、neutral、negative |

主键为 `news_id`，外键为 `stock_id`。适合支持“某股票最近有哪些公告摘要”“最近负面新闻较多的股票有哪些”“新闻情绪和行情变化是否能一起展示”等问题。

### `watchlists`：自选股表

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| `watchlist_id` | INTEGER | 主键，自选记录 ID |
| `user_id` | VARCHAR | 用户 ID |
| `stock_id` | INTEGER | 外键，关联 `stocks.stock_id` |
| `created_at` | DATETIME | 加入时间 |
| `note` | TEXT | 备注 |

主键为 `watchlist_id`，外键为 `stock_id`。该表是可选表，用于演示用户个性化查询。适合支持“我的自选股中最近涨幅最高的是哪几支”“某用户关注了哪些行业的股票”等问题。

## 3. 示例自然语言问题

### 单表查询

1. 查询所有在上交所上市的股票。
2. 查询股票代码为 600000 的股票名称和所属行业。
3. 查询所有 A 股市场中的股票基础信息。
4. 查询 2020 年以后上市的股票有哪些。

### 多表连接

5. 查询每支股票所属的板块名称。
6. 查询新能源板块中所有股票的最新收盘价。
7. 查询某支股票最近发布的新闻标题和收盘价。
8. 查询各行业股票在最近一个交易日的平均成交额。

### 聚合统计

9. 各行业分别有多少支股票。
10. 各行业平均市盈率是多少。
11. 最近一个交易日全市场平均涨跌幅是多少。
12. 每个板块最近一个交易日的总成交量是多少。

### 时间范围查询

13. 某支股票最近一年的最高收盘价是多少。
14. 查询过去 30 个交易日某股票的收盘价走势。
15. 最近 30 个交易日收盘价涨幅最高的 5 支股票是什么。
16. 查询某股票在 2024 年第一季度的平均成交量。

### 排序 Top-N 查询

17. 最近一个交易日成交量最高的 10 支股票是什么。
18. 市盈率最低的 10 支股票有哪些。
19. 最近一个交易日涨幅最高的 5 支股票有哪些。
20. 净利润最高的 10 支股票有哪些。

### 财务指标查询

21. 哪些股票的市盈率低于 20。
22. 哪些股票的 ROE 大于 15% 且负债率低于 50%。
23. 查询各行业平均 ROE 和平均负债率。
24. 查询某股票最近一期的收入、净利润和毛利率。

### RAG 概念解释

25. 市盈率是什么意思。
26. ROE 和净利率有什么区别。
27. 为什么不能只根据市盈率判断股票是否便宜。
28. 成交量和成交额有什么区别。

### Text2SQL + RAG 混合问答

29. 查询市盈率低于 20 的股票，并解释市盈率低可能代表什么。
30. 找出最近一个交易日涨幅最高的 5 支股票，并说明涨跌幅字段的含义。
31. 查询 ROE 大于 15% 的股票，并解释 ROE 指标的局限性。
32. 查询某股票最近 30 个交易日的走势，并说明为什么短期走势不能直接作为投资建议。

## 4. RAG 知识库文档建议

| 文档类型 | 建议内容 | 用途 |
| --- | --- | --- |
| 股票基础概念说明 | 股票、交易所、行业、板块、上市日期、市场类型等概念 | 回答基础概念类问题 |
| 财务指标解释 | 市盈率、市净率、ROE、营收、净利润、毛利率、负债率等指标定义和局限性 | 解释财务指标含义 |
| 行情字段说明 | 开盘价、收盘价、最高价、最低价、成交量、成交额、涨跌幅等字段口径 | 帮助用户理解查询结果 |
| 常见投资风险提示 | 数据滞后、模型误差、指标局限、市场波动、非投资建议声明 | 控制演示边界和风险表达 |
| 数据字段口径说明 | 数据更新频率、单位、缺失值处理、报告期含义 | 提高查询结果解释一致性 |
| 系统使用说明 | 如何提问、如何查看 SQL、如何理解表格和图表 | 支持用户上手系统 |
| SQL 查询示例说明 | 常见自然语言问题与 SQL 示例 | 后续用于 SQL 示例检索或 few-shot prompt |

RAG 文档用于解释概念、字段和系统规则，不用于给出具体投资建议。回答中如果涉及股票选择、估值判断或风险判断，应明确提示“仅为课程演示和指标解释，不构成投资建议”。
